# 仓库整理与修复

本次以已有计算机设计大赛项目为基础整理仓库，未把旧功能表述为黑客松赛期新开发功能。

- 从四个 Unity 导出包恢复资源及原始 `.meta` GUID，按模块分开存放，避免同名脚本冲突。
- 修正 12 个自有脚本的文件名与公开类名不一致问题，包括相互错放的音效/烟雾脚本及重复三遍的 Kinect 评估器文件名。文件和 `.meta` 同步移动，保持资源身份；映射见 `script-renames.json`。
- 将原 GB18030 编码的 C# 文件转为 UTF-8，保留代码和中文文本，避免导入时编码异常。
- 将心率接收器默认端口由 5005 改为 8080，与 ESP32 文档协议一致，避开 Kinect 姿态接收默认端口。已序列化组件需在 Inspector 手动更新。
- 用独立解析器替换从整个字符串拼接数字的旧实现。CSV 只使用第一列心率；拒绝损坏数据、NaN、Infinity、负值和超出协议范围的心率。保留单值、`BPM: 78`、`78 BPM` 输入支持。
- 移除未连接时虚构的初始 70 BPM，断流超过 3 秒显示断开；接收器禁用时释放端口，绑定失败能清理状态。
- 从原生理反馈文档恢复 Arduino `.ino`；将网络配置拆成忽略的 `config.h` 和无真实密码的示例文件。硬件采样实现沿用原逻辑，尚未实机验证。
- 添加 README、导入/依赖/协议文档、第三方来源说明、Git 忽略规则、UDP 模拟工具和解析回归测试。

原目录中的 Word/PDF/PPT、原始 Unity 包和重复视频均保持不变。没有在缺少原设置的情况下编造 Unity 项目锁定文件、移动端源码、构建产物或实测性能结果。
